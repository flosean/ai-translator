NextAI 翻譯 — 使用說明
============================

【啟動】
雙擊 NextAITranslator.exe。程式會常駐在系統匣（右下角工具列）。

【開啟翻譯視窗】
- 按全域熱鍵（預設 Ctrl+Alt+Z），或
- 雙擊系統匣圖示，或
- 系統匣圖示按右鍵 →「顯示翻譯視窗」

【第一次設定 API】
1. 開啟視窗後點「設定」
2. 選供應商（Gemini 或 OpenAI）
3. 貼上你的 API Key
4. 模型欄會自動列出可用模型（也可按「重新整理」），從下拉選一個
5. 按「儲存」

【介面縮放（整個介面一起放大，4K 螢幕用）】
- 設定裡的「介面縮放」可選 100%～200%，或
- 視窗開啟時按 Ctrl + 加號放大、Ctrl + 減號縮小、Ctrl + 0 還原。
  調整後會自動記住。

【翻譯字級（只放大輸入/輸出的文字）】
- 設定裡的「翻譯字級」可選 14～32，或
- 把滑鼠移到輸入框或輸出框上，按住 Ctrl + 滾動滾輪即可即時放大/縮小文字。
  這個只影響翻譯內容的字，不會動到其他介面元件。調整後會自動記住。

【輸入/輸出框比例】
- 把滑鼠移到中間控制列（「翻譯成」那一排）的空白處，按住上下拖曳，
  即可調整輸入框與輸出框的高度比例。調整後會自動記住。

【語調】
- 主視窗「清除」左邊的「語調」下拉可直接選：默認（自然）/ 專業 / 友善 / 正式 / 口語。
  會影響翻譯輸出的語氣，選了立即生效並記住。

【目前模型】
- 主視窗左下角「設定」按鈕旁會顯示目前使用的模型名稱。

【提示詞（進階）】
- 設定裡的「提示詞」可直接檢視與編輯給模型的指令。
- 用 {target} 代表目標語言（例如會自動替換成「Traditional Chinese」）。
- 選的語調會自動接在提示詞後面。
- 按「還原預設」可回到內建提示詞。改完按「儲存」。

【清除 / 複製】
- 「清除」鈕（語言列右側）清空輸入框。
- 「複製」鈕（翻譯鈕左側）複製翻譯結果。

【翻譯】
在上方輸入框貼上文字 → 選擇「翻譯成」的語言 → 按「翻譯」。
也可以輸入完直接按 Ctrl+Enter 開始翻譯，不用點按鈕。
結果會即時逐字顯示，按「複製」可複製結果。

【自動翻譯（選用）】
在「設定」勾選「按熱鍵叫出視窗時，自動貼上剪貼簿並翻譯」。
之後只要先複製文字，再按熱鍵，就會自動貼上並開始翻譯。

【自訂熱鍵】
在「設定」的「全域熱鍵」欄修改，格式如：Ctrl+Alt+Z、Win+Shift+F5、Ctrl+1。

【結束程式】
系統匣圖示按右鍵 →「結束」。
（關閉視窗或按 Esc 只會隱藏視窗，程式仍在系統匣常駐。）

【設定檔位置】（純文字，可手動編輯）
%APPDATA%\NextAITranslator\config.json
通常是：C:\Users\你的帳號\AppData\Roaming\NextAITranslator\config.json

【系統需求】
需要 .NET 8 Desktop Runtime（你目前這台電腦已安裝）。
若日後換電腦或重灌後無法啟動，到以下網址安裝即可：
https://dotnet.microsoft.com/download/dotnet/8.0  →「.NET Desktop Runtime」
