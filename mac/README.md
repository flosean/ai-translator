# NextAI 翻譯 for macOS

原生 SwiftUI 版，限定 Apple Silicon 與 macOS 14 以上。沒有第三方套件。

## 安裝與自動啟動

已有成品時，將 `dist-mac/NextAI 翻譯.app` 拖進「應用程式」資料夾並開啟即可，不需要 Xcode。

在 App「設定」→「操作」勾選「登入時自動啟動」，之後登入 Mac 就會啟動翻譯器；取消勾選即可關閉。若顯示需要允許，按「開啟登入項目設定」到 macOS 系統設定中允許。從系統設定修改登入項目後，回到 App 會更新勾選狀態。請先安裝並從 `.app` 開啟，再設定自動啟動。

## 從原始碼執行

需要 Xcode 26 以上來編譯 Liquid Glass API；產生的 App 仍支援 macOS 14 以上。用 Xcode 開啟 `Package.swift` 後按 Run，或：

```zsh
swift run
```

從選單列「NextAI 翻譯」開啟設定，填入 Gemini API Key 後按「儲存 API Key」。模型預設為 `gemini-3.5-flash`，也可按「讀取模型」後選擇帳號可用的模型。Key 以明文存在 `~/Library/Application Support/NextAITranslator/credentials.json`（目錄權限 700、檔案權限 600，僅目前帳號可讀寫），模型、提示詞與介面偏好則放在 `UserDefaults`。舊版的 `gemini-2.0-flash` 已被 Google 關閉，App 會自動遷移成 `gemini-3.5-flash`。

預設全域快捷鍵是 `⌥⌘Z`，可在設定頁改成 `⌥⌘` 加任一英文字母。勾選「叫出時自動翻譯剪貼簿」後，按快捷鍵會帶入剪貼簿文字並直接翻譯。

輸入與翻譯結果的高度可自由分配：拖曳中間控制列下方的灰色把手，上下調整兩個區域的大小。兩區各保留最小可閱讀高度，避免被完全收起。

App 圖示採用藍綠色玻璃對話框與 A／文翻譯符號。介面採用系統材質背景、圓角文字區與精簡控制列。視窗採用緊湊邊距與文字區內距，最小可縮至 560 × 520；頂部可切換目標語言，語調選單點開後直接列出所有選項與目前選擇；原文右上角清除內容，譯文右上角複製結果；左下角開啟設定，右下角翻譯（也可按 `⌘Return`）。macOS 26 以上使用原生 Liquid Glass 按鈕與選單；macOS 14／15 使用系統材質及標準按鈕。明暗模式隨系統切換，背景配合「降低透明度」設定。 設定視窗改為緊湊的 560 × 440 欄位排列，金鑰儲存與模型讀取按鈕放在各自欄位旁，底部固定顯示「完成」按鈕，按下或按 Esc 即可關閉，不必捲動尋找。

關閉視窗後仍可從選單列、Dock 或快捷鍵重新開啟。清除或重新翻譯時會取消舊請求，避免舊回應混入新結果；快捷鍵註冊失敗會顯示提示。新版不再存取鑰匙圈，舊版使用者需重新輸入並儲存一次 API Key；清空後儲存會刪除本機金鑰檔。

串流只有收到正常結束訊號才視為成功。若回應截斷、JSON 損壞、達到輸出長度上限或被安全機制中止，會保留已收到的部分文字並顯示錯誤，請縮短原文或重試。

## 測試

在專案根目錄執行 `swift test --package-path mac`。測試涵蓋串流解析、正常完成與截斷／損壞／異常結束的假 HTTP 回應、取消與替換翻譯、本機金鑰保存與檔案權限、設定隔離與還原、模型遷移、畫面渲染及上下區域高度計算。網路測試使用獨立 URLSession 與 URLProtocol 假回應；金鑰及設定測試使用測試資料與暫存路徑，不讀取真實金鑰或呼叫付費 API。實際滑鼠拖曳仍需人工驗證；本次以獨立假資料預覽 App 確認拖曳調整上下區塊比例，並檢查明暗模式與小視窗排列。
