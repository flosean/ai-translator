# NextAI 翻譯 for macOS

原生 SwiftUI 版，限定 Apple Silicon 與 macOS 14 以上。沒有第三方套件。

## 安裝與自動啟動

已有成品時，將 `dist-mac/NextAI 翻譯.app` 拖進「應用程式」資料夾並開啟即可，不需要 Xcode。

在 App「設定」→「操作」勾選「登入時自動啟動」，之後登入 Mac 就會啟動翻譯器；取消勾選即可關閉。若顯示需要允許，按「開啟登入項目設定」到 macOS 系統設定中允許。從系統設定修改登入項目後，回到 App 會更新勾選狀態。請先安裝並從 `.app` 開啟，再設定自動啟動。

## 從原始碼執行

用 Xcode 開啟 `Package.swift` 後按 Run，或：

```zsh
swift run
```

從選單列「NextAI 翻譯」開啟設定，填入 Gemini API Key 後按「儲存 API Key」。模型預設為 `gemini-3.5-flash`，也可按「讀取模型」後選擇帳號可用的模型。Key 只會放進 macOS Keychain，模型、提示詞與介面偏好則放在 `UserDefaults`。舊版的 `gemini-2.0-flash` 已被 Google 關閉，App 會自動遷移成 `gemini-3.5-flash`。

預設全域快捷鍵是 `⌥⌘Z`，可在設定頁改成 `⌥⌘` 加任一英文字母。勾選「叫出時自動翻譯剪貼簿」後，按快捷鍵會帶入剪貼簿文字並直接翻譯。

輸入與翻譯結果的高度可自由分配：拖曳中間控制列下方的水平分隔線，上下調整兩個區域的大小。兩區各保留最小可閱讀高度，避免被完全收起。

內容區直接從輸入框開始，不重複顯示 App 標題；左下角齒輪可開啟設定。

關閉視窗後仍可從選單列、Dock 或快捷鍵重新開啟。清除或重新翻譯時會取消舊請求，避免舊回應混入新結果；快捷鍵註冊失敗會顯示提示。更新 API Key 會直接修改鑰匙圈項目，避免先刪除原金鑰。

## 測試

在專案根目錄執行 `swift test --package-path mac`。測試涵蓋串流解析、取消與替換翻譯、設定隔離與還原、模型遷移、畫面渲染及上下區域調整；使用測試金鑰與獨立偏好儲存，不讀取真實鑰匙圈，也不呼叫付費 API。
